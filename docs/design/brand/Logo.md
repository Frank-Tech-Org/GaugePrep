# Logo

The GaugePrep logo is the **Speaking book** mark with the Figtree wordmark. Use the files in the Logos group exactly as supplied; never redraw, recolour, stretch or rebuild them.

## Which file

- `gaugeprep_lockup-horizontal.svg`: the default sign-off, website header, documents, slides.
- `gaugeprep_lockup-stacked.svg`: square and tall spaces, posters, the end card of a film.
- `gaugeprep_mark.svg`: the mark alone, once people already know the name (social avatar, app tile, watermark).
- `gaugeprep_mark-small.svg`: 16 to 48px only (favicons, tiny UI). Four pages, no shadow layer, built to stay readable.
- `gaugeprep_mark-reversed.svg` and `gaugeprep_lockup-horizontal-white.svg`: on `ink` and other dark grounds.
- `gaugeprep_mark-mono-ink.svg` and `gaugeprep_mark-mono-white.svg`: one-colour print, stamps, embroidery, engraving.
- `gaugeprep_emblem.svg`: the seal ("MEASURE · TRAIN · REHEARSE") for certificates of completion, results reports and merchandise. Never as the main logo.
- `gaugeprep_app-icon.svg` and `gaugeprep_app-icon-maskable.svg`: the installed web app icon and PWA manifest.

## Clear space and size

- Clear space on every side equals the height of the amber page. Nothing (text, edges, other logos) enters it.
- Minimum sizes: horizontal lockup 120px wide on screen, 30mm in print; stacked lockup 72px wide; full mark 32px; below 32px switch to `gaugeprep_mark-small.svg`.

## Grounds

- Full colour on `paper`, white, or light photography with calm areas.
- Reversed on `ink` or `depth`, or dark photography.
- Mono when only one ink is available.
- Never on Amber, on mid-teal (`sea`, `lagoon`), or on busy photos without a calm zone.

## Never

- Recolour the pages, swap the amber page, or add pages.
- Change the wordmark's font, spacing or case ("Gaugeprep", "GAUGEPREP" in the lockup).
- Add effects: outlines, glows, drop shadows, gradients. The approved 3D render is the only dimensional version.
- Rotate, skew, crop, or put the mark inside another shape.
- Pair it with exam-owner logos as if partnered.
