# LevelBadge

A level written in the exam's own scale: the consumer provides `level` ("B2", "NCLC 7", "Band 6.5") and an optional `label` ("Upper intermediate", "Your target"). Tone `reading` marks the learner's current estimate (`accent-soft` ground, `accent` level disc); `target` is the goal (dashed `line-strong` border); `neutral` lists other levels.

- Show at most one `reading` badge per view; it must match the ScoreGauge on the same screen.
- Never invent a scale: use the official level names of the exam in question, descriptively, with no exam-owner logos.
