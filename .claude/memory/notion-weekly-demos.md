The owner chose Notion for progress reports and the Friday demo (2026-10-29). The private page "LinguaMentor Studio" (https://app.notion.com/p/4083ae0faeec81e090a9f2d9a6df4147) holds the links and the "Weekly demos" database (https://app.notion.com/p/3ae280efae1e4a9ebce8b2499dccd65a, data source collection://b059f097-50cf-4c20-92d6-ce8d8d55a766). Each entry has Week, Demo date, Status, Security, Performance, Needs you and Links.

The report is about delivery: per milestone, tickets released, on staging, in progress and not started, with a forecast, then what was delivered this week in plain words and what remains. Security and performance are one line each.

**Why:** the owner judges progress by features delivered against features still to deliver, and sessions are not always open, so the report must not depend on one.
**How to apply:** `product-manager` has the Notion tools and posts it through `/pm report` the day before the Friday demo. The demo time is not fixed yet, so ask the owner. See [[studio-reset-owner-decisions]].
