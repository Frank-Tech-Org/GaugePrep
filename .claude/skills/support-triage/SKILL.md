# Support triage

1. Classify: bug, billing, account, exam question, feedback.
2. Find the answer in the help centre. If there is none, draft one and hand it to `content-marketer`.
3. Never ask for a password, card number or ID document. Refer to the learner by the anonymous ID only.
4. Reply in the learner's language, short, with the next step and what to expect.
5. A refund, a legal request or a score claim goes to the owner through `product-manager`.
6. Three messages on one problem in a week: write one draft ticket (title, type, area, priority, evidence) for `product-manager`.
