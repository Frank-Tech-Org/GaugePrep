# Photo credits

One row per photo. Exports share the row of their photo: `auth-measure-m.webp` and `auth-measure-l.webp` belong to the row with Id `auth-measure` (the suffix `-s`, `-m` or `-l` is the size). The pull request check reads the table below and fails, naming the photo, when a file has no row, a cell is empty or a file is over 120 kB.

- Id: file name without extension and without the size suffix.
- Source: link to the photo's own page, starting with `https://`.
- Author: the photographer as named on that page.
- Licence: the licence name.
- Commercial-use terms: the licence's own words on commercial use, in quotation marks, read on the licence page.
- Checked: the date the licence was read, `YYYY-MM-DD`.
- Alt FR and Alt EN: alt text written separately in each language.

No photo shows an identifiable person unless the licence states a model release. Phones never download these photos. Keep cell text free of the `|` character.
